
FACTORIAL
The base case returns 1 when n is 0 or 1. The recursive case multiplies n by factorial(n - 1). Negative inputs are rejected.

FIBONACCI
The base cases return 0 for F(0) and 1 for F(1). The recursive case adds fibonacci(n - 1) and fibonacci(n - 2). Negative inputs are rejected.

STRING REVERSAL
The base case returns a string containing zero or one character unchanged. The recursive case reverses the substring after the first character and appends the first character at the end.

BINARY SEARCH
The base case returns -1 when the search interval becomes empty or returns the index when the target is found. The recursive case compares the target with the middle element and searches the appropriate half. The array must be sorted.

RECURSION SUMMARY
Recursion solves a problem by having a function call itself on a smaller version of the same problem. Every recursive function needs a base case to stop further calls and a recursive case that makes progress toward that base case. Iteration uses loops to repeat operations, while recursion uses function calls and the call stack.

Recursion is useful for problems that naturally divide into smaller subproblems, such as tree traversal, divide-and-conquer algorithms, factorial calculation, and binary search. It can make code easier to understand when the recursive structure closely matches the problem. However, recursion may consume additional stack memory and cause overhead from repeated function calls. Some recursive algorithms, such as the basic Fibonacci implementation, also repeat calculations unnecessarily. Iterative solutions are often more memory-efficient and faster for simple repetitions. The best approach depends on clarity, performance, memory usage, and the problem's structure.
